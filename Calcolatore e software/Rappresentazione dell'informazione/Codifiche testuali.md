>[!note]
>Esistono diverse codifiche per rappresentare il testo, di seguito mostriamo le codifiche ASCII e Unicode.

### Codifica ASCII
>[!note]
>Nello standard ASCII base si intende rappresentare i seguenti caratteri:
>- alfabeto base: $\set{a .. z,A .. Z}$
>- caratteri numerici: $\set{0 .. 9}$
>- simboli di interpunzione
>- caratteri speciali (new-line, space, ...)
>
>La lunghezza della codifica è $7\text{ bit}$. Lo standard ASCII base è stato poi esteso a $8\text{ bit}$ con l'aggiunta di caratteri nazionali $\set{à\cdots ù}$, simboli e cornici.

Ogni carattere nello standard ASCII esteso corrisponde ad un byte, e quindi anche ad un valore numerico.

### Codifica Unicode
>[!note]
>La codifica Unicode è uno standard compatibile con il codice ASCII che utilizza $16\text{ bit}$ per rappresentare i caratteri, permettendo quindi di rappresentare molti più caratteri. Tuttavia la dimensione dei file risulta raddoppiata rispetto ad ASCII.
